# Security policy

## Supported releases

Security fixes are made against the latest tagged PyCastle release. Earlier
releases are not supported; upgrade to the latest tag before reporting a
problem that may already have been fixed.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting form](https://github.com/krishnakartik1/pycastle/security/advisories/new).
Private vulnerability reporting will be enabled when the repository becomes
public. If that form is unavailable, email
[krishnakartik1@gmail.com](mailto:krishnakartik1@gmail.com).

Include the affected version, impact, reproduction steps, and any known
mitigation. Do not include credentials, tokens, or other secrets in the report.
